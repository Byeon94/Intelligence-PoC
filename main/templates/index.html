업무 인텔리전스 홈POC

👋 업무 인텔리전스 홈 소개

사내 업무에 필요한 정보를 한 곳에 모아 보여주는 사내 정보 포털 POC입니다.

기능

  • 📰 뉴스 — 오늘의 포인트 뉴스 AI 브리핑과 카테고리별(증권금융/금융/투자/IT) 최신 기사
  • 📜 정책 — 금융당국·유관기관 동향, 국회 법안, 연구·논문을 AI가 하루 한 번 수집
  • 📈 자본시장 데이터 — 국내외 주요 지수, 자금동향 지표
  • 🗂️ DART 공시 — 담보대출·우리사주 금융 수요와 연관될 수 있는 공시를 하루 한 번 수집
  • 📅 캘린더 — 공모주·주요 권리일정 관련 DART 공시 제출일을 월별로 표시

환경

  • ⚙️ 프레임워크: Flask (Python)
  • 🗄️ 데이터베이스: Supabase
  • 🐙 소스관리: GitHub
  • 🚀 배포: Render
  • 💻 IDE: Visual Studio

연결

  • 📊 라이브러리: yfinance(미국지수)
  • 🔌 API: 네이버 뉴스 API, 네이버 금융 API(국내지수), 금융감독원 Dart API
  • 🤖 AI: Google AI Studio(Gemini)
  • 🔗 참고사이트: 금융투자협회 자본시장 통계
