매일 새벽 자동 수집(배치)

매일 00:01 KST에 GitHub Actions가 /internal/warmup을 호출해 위 데이터의 스냅샷을 미리 만들어 DB에 저장해둡니다. 화면 접속 시에는 이 스냅샷만 읽으므로 사용자 접속 자체가 외부 API를 재호출하지 않으며, 원천 장애 시에도 직전 스냅샷을 그대로 보여줍니다.

  • 🕒 모든 AI 생성(브리핑·뉴스 선별·업종 분류 등)은 이 새벽 배치에서만 수행됩니다 — 비용 통제를 위해 화면에는 재생성 버튼이 없고 배치 전용입니다
  • 🕒 여신 기업분석은 종목별로 당일 첫 조회 결과를 DB에 저장해, 같은 날 같은 종목 재조회 시 외부 API를 재호출하지 않습니다
  • 🟢 연결됨 배지는 실데이터, 샘플·큐레이션 배지는 원천 일시 오류 시 대체 데이터입니다
