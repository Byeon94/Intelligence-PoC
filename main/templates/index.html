업무 인텔리전스 홈POC

👋 업무 인텔리전스 홈 소개

사내 업무에 필요한 정보를 한 곳에 모아 보여주는 사내 정보 포털 POC입니다.

기능

  • 📰 뉴스 — 키워드로 네이버 뉴스를 검색하고 AI가 핵심만 요약
  • 📜 정책 — 금융당국·유관기관 동향, 국회 법안, 연구·논문을 AI가 하루 한 번 수집
  • 📈 자본시장 데이터 — 국내외 주요 지수, 자금동향 지표

환경

  • ⚙️ 프레임워크: Flask (Python)
  • 🗄️ 데이터베이스: Supabase
  • 🐙 소스관리: GitHub
  • 🚀 배포: Render

연결

  • 📊 라이브러리: yfinance(미국지수)
  • 🔌 API: 네이버(뉴스·금융), Google Gemini
